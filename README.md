# frontend-css-assignments
A collection of CSS practice tasks completed during my Web Development Internship, covering CSS Grid, Layout Design, Transitions, Transformations, Animations, and CSS Loaders.

## Projects and Tasks

* CSS Selector Practice Page
* Box Model Design Practice
* Shape and Border Design Tasks
* Transform and Transition Examples
* Background Image and Opacity Effects
* Flexbox Navigation Bar
* Flexbox Layout Practice
* Grid Layout Templates
* Responsive Webpage Layouts
* Animated CSS Loader

## What I Learned

* Applied different CSS selectors effectively.
* Understood CSS specificity and inheritance rules.
* Built layouts using the CSS Box Model.
* Created visual effects with transitions and transforms.
* Used Flexbox for alignment and responsive layouts.
* Designed complex layouts using CSS Grid.
* Implemented CSS animations and loaders.
* Developed responsive webpages using media queries.
* Improved practical CSS development and debugging skills.
